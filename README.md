# PowerBi-sales-dashboard

## 📌 Overview
This project presents an interactive *Power BI dashboard* built to analyze laptop sales data.  
The dashboard helps identify sales trends, top-performing brands, pricing patterns, and overall business insights.

## 🛠 Tools & Technologies
- Power BI Desktop
- DAX
- Excel / CSV
- Data Cleaning & Transformation

## 📊 Key Insights
- Identified top laptop brands by total revenue
- Analyzed price vs sales volume relationship
- Monthly and yearly sales trend analysis
- Category-wise and brand-wise performance comparison

## 📈 Dashboard Features
- Interactive slicers (brand, price range, time period)
- KPI cards for revenue and sales
- Bar charts, line charts, and trend visuals
- Clean and user-friendly layout
